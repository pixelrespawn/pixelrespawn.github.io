# Using skins

Controller skins change the appearance of Linkboy’s on-screen controller.

## Download a skin

Browse the skin downloads section and download a **`.lbskin`** file to your device. Keep it as a single file; you do not need to extract it.

## Install a skin

1. Open Linkboy’s **Settings** and go to **Virtual controller → Layouts & skins**.
2. Tap **+**, then **Install skin**.
3. Select the downloaded `.lbskin` file and confirm installation.

Depending on its type, the installed skin appears under **Full skins** or **Control skins**.

## Full skins

Full skins include layouts and artwork, such as backgrounds, overlays, and control images. To use a full skin, create a layout profile from it:

1. Under **Full skins**, find the installed skin.
2. Tap the **+** icon next to the skin to create a profile.

The new profile appears under **Layout profiles** and is automatically selected.

You can use the profile as it is or edit its layout anytime—for example, to move or resize controls, adjust the game screen, or add buttons.

When a full skin is updated, its updated layouts are not applied to existing profiles you have edited—for example, by adding buttons. To use the updated layout, create a new profile from the updated skin.

## Control skins

Control skins change the control images used by your active layout profile while keeping its layout.

If a layout profile was created from a full skin, it always uses that skin. Selecting a control skin does not override it.

Select a skin under **Control skins** to apply it to your active profile. To return to the standard control images, select **Default skin**.
